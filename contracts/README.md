# ChainGuard AI

## О приложении

ChainGuard AI — проект приложения для работы с данными о переводах в блокчейне. Его текущая основа — смарт-контракт `TransferVault`: он позволяет записать адрес получателя и сумму в журнал событий сети. Благодаря этому внешнее приложение сможет получать историю таких записей и показывать её пользователю.

Сейчас в репозитории реализована только контрактная часть. Пользовательского интерфейса, сервера и функций на основе ИИ здесь пока нет. Контракт написан на Solidity, а для сборки и тестирования используется Foundry.

## Сценарий работы

1. Пользователь вызывает `recordTransfer(recipient, amount)` и указывает получателя и сумму.
2. Контракт проверяет данные: адрес получателя не должен быть нулевым, сумма должна быть больше нуля.
3. Контракт увеличивает `transactionCount` и создаёт событие `TransferRecorded`. В нём указаны отправитель вызова, получатель, сумма и время блока.
4. Внешний интерфейс при его появлении сможет читать эти события и отображать историю записей.

**Важно:** сейчас приложение не переводит, не принимает и не хранит ETH или токены. Событие подтверждает только запись данных, а не реальный перевод средств. Вызвать функцию может любой адрес; `owner` хранит адрес создателя контракта, но не даёт ему особых прав.

## Состав проекта

- `src/TransferVault.sol` — смарт-контракт.
- `test/TransferVault.t.sol` — тесты успешной записи и отклонения неверных данных.
- `foundry.toml` — настройки Foundry.

## Требования

- [Foundry](https://book.getfoundry.sh/getting-started/installation)
- Библиотека `forge-std` для тестов. Установите её после клонирования проекта из каталога `contracts`: `forge install foundry-rs/forge-std --no-git`.

## Запуск проверок

Выполняйте из каталога `contracts`:

```sh
forge build
forge test
forge fmt --check
```

Исходный код находится в `src/`, тесты — в `test/`, настройки Foundry — в `foundry.toml`.
