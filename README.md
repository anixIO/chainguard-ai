# ChainGuard AI

Прототип приложения для работы с записями о переводах в блокчейне. Контракт `TransferVault` записывает сведения в события и считает количество записей. Веб-интерфейс позволяет подключить кошелёк, выбрать развёрнутый контракт, создать запись и посмотреть последние события сети. Контракт не переводит средства и не проверяет, что перевод действительно произошёл.

В репозитории пока нет функций ИИ и сервера. Для работы интерфейса нужен развёрнутый экземпляр контракта и браузерный Ethereum-кошелёк.
