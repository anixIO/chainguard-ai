# ChainGuard AI

Проект приложения для работы с записями о переводах в блокчейне. Сейчас реализована контрактная часть на Solidity: `TransferVault` записывает сведения в события и считает количество записей. Контракт не переводит средства и не проверяет, что перевод действительно произошёл.

Описание проекта, установка зависимостей и команды проверки находятся в [contracts/README.md](contracts/README.md).
