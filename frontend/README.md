# Веб-интерфейс ChainGuard AI

Интерфейс для работы с уже развёрнутым контрактом `TransferVault`. Он подключается к локальному Anvil или браузерному Ethereum-кошельку, показывает счётчик записей и события из последних 5 000 блоков, а также позволяет вызвать `recordTransfer`.

## Запуск

Требуются Node.js 20.19+ или 22.12+. Для локального режима нужен Anvil. Если в браузере есть кошелёк с поддержкой EIP-1193, интерфейс использует его вместо Anvil.

```sh
cd frontend
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Подключите кошелёк или локальный Anvil и введите адрес `TransferVault`, развёрнутого в выбранной сети. Адрес контракта сохраняется в `localStorage` отдельно для каждой сети. Сам контракт из интерфейса не развёртывается.

Для работы без браузерного кошелька запустите `anvil` в отдельном терминале. В этом режиме интерфейс подключится к `http://127.0.0.1:8545` и использует первый разблокированный тестовый аккаунт Anvil. Для записи подтверждение в кошельке не требуется. Прототип работает только с локальной сетью Anvil (ID 31337).

Чтобы развернуть контракт в локальной сети, из каталога `contracts` выполните:

```sh
forge create src/TransferVault.sol:TransferVault --rpc-url http://127.0.0.1:8545 --unlocked --from 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 --broadcast
```

Скопируйте адрес из строки `Deployed to` в интерфейс. После перезапуска Anvil состояние сети сбрасывается: контракт нужно развернуть заново.

## Ограничения

- Контракт только записывает заявление о переводе. Он не переводит и не хранит средства.
- Сумма — положительное целое число без обозначения валюты или токена.
- Для чтения событий используется RPC выбранной сети. Показаны до 50 последних событий из последних 5 000 блоков.
- Показатели панели рассчитываются по всем полученным событиям в этом окне. Поиск работает по адресу отправителя, получателя и хэшу транзакции. CSV содержит все найденные записи, даже если таблица показывает только первые 50.
- При работе через браузерный кошелёк запись требует подтверждения транзакции и оплаты газа. Интерфейс ждёт подтверждения до двух минут.

Проверка сборки: `npm run build`.
